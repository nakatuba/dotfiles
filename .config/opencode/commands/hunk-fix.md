---
description: 自分が書いたノートに沿って修正する（Plan モードでは計画だけを出す）
---

hunk-review スキルを読み込み、開いている Hunk セッションで私が書いたノートに沿って対応してください。今が Plan モードなら修正計画だけを立て、そうでなければ修正まで行うこと。

Input: $ARGUMENTS

## 共通の手順

1. `hunk session list` でセッションを探す。見つからなければ、ターミナルで `hunk diff --watch` を起動するよう伝えて止まる
2. `hunk session comment list --repo . --type user --json` で私が書いたノートを取得する。ノートがなければその旨を伝えて止まる
3. ノートごとに、対象のファイルと行を読み、修正方針を考える

## Plan モードの場合

コードの修正も、hunk への返信も行わないこと。

4. 次の形で修正計画を日本語で示す
   - ノートごとに: ノート ID、対象のファイル・行、指摘の要点、修正方針
   - 方針が分かれる指摘や、修正内容に迷う指摘は「保留」とし、理由と確認したいことを書く
5. 計画の最後に、実装時の手順として次の内容を含める
   - 計画に沿って修正し、各ノートに `hunk session comment add --repo . --reply-to <note-id> --summary "..."` で何をどう直したかを日本語で返信する
   - 保留のノートには、確認したいことを返信で残す
   - git commit は行わず、変更は作業ツリーに残す
6. 計画を示したら、私の確認を待つ

## それ以外のモードの場合

4. ノートごとに修正し、`hunk session comment add --repo . --reply-to <note-id> --summary "..."` で何をどう直したかを日本語で返信する
   - 方針が分かれる指摘や、修正内容に迷う指摘は直さず、返信で質問を残す
5. 最後に、修正したノートと保留したノート（質問内容つき）を日本語で一覧にして報告し、保留分の判断を確認する

どちらのモードでも git commit は行わず、変更は作業ツリーに残したままにすること。
